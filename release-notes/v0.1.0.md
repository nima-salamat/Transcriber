# Transcriber 0.1.0

The first public release of the modular PySide6 desktop application.

## Included

- Local-first audio transcription with Faster-Whisper model discovery and management.
- Microphone recording with live waveform, device selection, pause/resume, save and discard.
- Transcript history and editing, subtitle studio, batch processing and non-destructive audio cleanup.
- Optional OpenCode ACP and local Ollama assistant integrations.
- A windowed Windows desktop application and per-user installer with Start Menu and optional desktop shortcuts.

## Install on Windows

Download \`Transcriber-Setup-0.1.0-x64.exe\` and run it. It installs for the current Windows user and does not require administrator privileges.

Speech-recognition model weights are not bundled. Install a compatible model from Model Library after launching the app.

## Notes

This is the first public release. See the repository README and Known Limitations for supported workflows and current feature boundaries.
