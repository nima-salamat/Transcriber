# Transcriber 0.2.0

The 0.2.0 release builds on the first public release with a broad round of desktop UX refinements, AI Assistant improvements and stronger Windows packaging.

## Highlights

- Refined the shared desktop design system and polished the Home, Recording, History, Model Library, Batch, Audio Cleanup, Transcript Editor and Subtitle Studio experiences.
- Improved the AI Assistant welcome state and suggested prompts, conversation layout, provider interactions and independent Stop control.
- Improved Home actions and the history sidebar presentation.
- Generated a multi-resolution Windows application icon from the bundled SVG, embedded it in the executable and added a PE-resource verification step before the installer is created.
- Made Start Menu and optional desktop shortcuts use the executable's embedded icon.
- Updated the automated release workflow to load version-specific release notes and verify that the installer is attached to the GitHub Release.

## Install on Windows

Download `Transcriber-Setup-0.2.0-x64.exe` and run it. The installer is per-user and does not require administrator privileges.

Speech-recognition model weights are not bundled. Install a compatible model from Model Library after launching the app.

## Notes

This release does not bundle ASR model weights. Review the repository README and [Known Limitations](../docs/KNOWN_LIMITATIONS.md) for supported workflows and current feature boundaries.
